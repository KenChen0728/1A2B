# 猜數字：幾A幾B

和朋友連線猜數字的手機網頁遊戲，也能一個人打魔王。

- 開始玩：<https://kenchen0728.github.io/1A2B/>
- 可以加到手機主畫面或安裝到電腦，遊戲裡的「？ 說明 → 加到主畫面」有各裝置的做法。
- 遇到問題：首頁最下面有版本號和「意見回饋」。
